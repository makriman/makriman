# Medium → makriman content migration

Pulled from https://makriman.medium.com/feed for migration into the makriman personal-brand repo.

- `INDEX.md` — title + publish date + URL table
- `index.json` — machine-readable inventory
- `posts/` — one Markdown file per article (YAML frontmatter + original HTML body from Medium RSS)

Canonical URLs remain on Medium until a lander/site greenlight. Do not deploy to makriman.com from this PR alone.
